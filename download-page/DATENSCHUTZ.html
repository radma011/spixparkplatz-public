2. Allgemeine Informationen zur Datenverarbeitung

Diese Datenschutzerklärung informiert Sie über die Art, den Umfang und den Zweck der Verarbeitung von personenbezogenen Daten in der mobilen Anwendung "spixparkplatz" (nachfolgend "App" genannt).

3. Erhobene Daten

3.1 Registrierungs- und Kontodaten

Bei der Registrierung und Nutzung der App werden folgende personenbezogene Daten erfasst:

  • E-Mail-Adresse: Erforderlich für die Registrierung und Anmeldung
  • Passwort: Wird verschlüsselt in Firebase Authentication gespeichert
  • Benutzername: Wird öffentlich angezeigt, um Sie in der App zu identifizieren
  • Telefonnummer: Optional, kann bei der Registrierung angegeben werden
  • Parkplatz-Nummern: Bis zu 3 Parkplatz-Nummern, die Sie besitzen
  • Parkanlagen-Code (Facility Code): Code der Parkanlage, der Ihrem Konto zugeordnet ist

3.2 Nutzungsdaten

Während der Nutzung der App werden folgende Daten erfasst:

  • Parkplatz-Anfragen: Von Ihnen erstellte Anfragen nach Parkplätzen (Zeitraum, Kommentare)
  • Parkplatz-Angebote: Von Ihnen erstellte Angebote für Parkplätze
  • Kommentare: Kommentare zu Parkplatz-Anfragen
  • FCM-Token: Token für Push-Benachrichtigungen (Firebase Cloud Messaging)
  • Geräteinformationen: Automatisch erfasste Informationen über Ihr Gerät für Push-Benachrichtigungen

3.3 Technische Daten

  • Geräte-ID: Zur Identifikation Ihres Geräts für Push-Benachrichtigungen
  • Betriebssystem: iOS oder Android
  • App-Version: Version der installierten App

4. Zweck der Datenverarbeitung

Die erfassten Daten werden für folgende Zwecke verarbeitet:

4.1 Bereitstellung der App-Funktionalität

  • Authentifizierung und Verwaltung Ihres Benutzerkontos
  • Erstellung und Verwaltung von Parkplatz-Anfragen und -Angeboten
  • Kommunikation zwischen Benutzern innerhalb der App
  • Zuordnung zu einer bestimmten Parkanlage (Multi-Tenant-System)

4.2 Push-Benachrichtigungen

  • Benachrichtigungen über neue Parkplatz-Angebote für Ihre Anfragen
  • Benachrichtigungen über neue Anfragen, die zu Ihren Parkplätzen passen
  • Erinnerungen vor Ablauf von Parkplatz-Zeiträumen
  • Benachrichtigungen über Statusänderungen (Annahme, Stornierung, etc.)

4.3 Verbesserung der App

  • Analyse der App-Nutzung zur Verbesserung der Funktionalität
  • Fehlerbehebung und technische Wartung

6. Datenweitergabe

6.1 Firebase Services (Google)

Die App nutzt folgende Firebase-Services von Google Ireland Limited (Gordon House, Barrow Street, Dublin 4, Irland):

  • Firebase Authentication: Zur Authentifizierung und Verwaltung von Benutzerkonten
  • Cloud Firestore: Zur Speicherung Ihrer Daten in einer Datenbank
  • Firebase Cloud Functions: Zur Verarbeitung von Backend-Logik und Push-Benachrichtigungen
  • Firebase Cloud Messaging (FCM): Zur Übermittlung von Push-Benachrichtigungen

Die Daten werden auf Servern in der Europäischen Union (EU) gespeichert. Google verarbeitet die Daten als Auftragsverarbeiter gemäß Art. 28 DSGVO.

Weitere Informationen zur Datenverarbeitung durch Google finden Sie in der Datenschutzerklärung von Google.

6.2 Weitergabe an andere Benutzer

Folgende Daten werden anderen Benutzern innerhalb derselben Parkanlage (gleicher Facility Code) angezeigt:

  • Benutzername: Wird bei Parkplatz-Anfragen, Angeboten und Kommentaren angezeigt
  • Telefonnummer: Nur wenn Sie diese in Ihrem Profil freigegeben haben
  • Parkplatz-Nummern: Werden bei Angeboten angezeigt
  • Parkplatz-Anfragen und Angebote: Inklusive Zeiträume und Kommentare

6.3 Keine Weitergabe an Dritte

Ihre Daten werden nicht an Dritte verkauft oder für Marketingzwecke verwendet. Eine Weitergabe erfolgt nur:

  • An andere Benutzer innerhalb derselben Parkanlage (wie oben beschrieben)
  • An Google als Dienstleister (Firebase Services)
  • Wenn gesetzlich vorgeschrieben oder zur Durchsetzung unserer Rechte

7. Datenspeicherung und -löschung

7.1 Speicherdauer

  • Aktive Konten: Ihre Daten werden gespeichert, solange Ihr Konto aktiv ist
  • Gelöschte Konten: Nach Löschung Ihres Kontos werden Ihre personenbezogenen Daten innerhalb von 30 Tagen gelöscht
  • Archivierte Anfragen: Erfüllte Parkplatz-Anfragen werden nach 3 Stunden automatisch archiviert und nach 14 Tagen gelöscht

7.2 Löschung Ihrer Daten

Sie können Ihr Konto und alle damit verbundenen Daten jederzeit löschen:

  1. Öffnen Sie die App
  2. Gehen Sie zu Ihrem Profil
  3. Wählen Sie "Konto löschen"
  4. Bestätigen Sie die Löschung

Nach der Löschung werden alle Ihre personenbezogenen Daten gelöscht, sofern keine gesetzlichen Aufbewahrungspflichten entgegenstehen.
